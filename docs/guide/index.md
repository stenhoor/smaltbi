# User guide

Working in the app, one part at a time. New here? The [Quick start](./quick-start) takes five minutes, and the
[tutorial](./tutorial) builds a report from CSV files.

- [Data](./data): load CSV, JSON and Parquet files from URLs or your computer, add SQL steps, refresh.
- [The model](./model): relate tables, write measures and calculated columns, add a date table, quick measures and
  what-if parameters.
- [Visuals](./visuals): add visuals, fill their wells, repeat a visual for each value, maps and plugin visuals.
- [Pages and interaction](./pages): filtering between visuals, arranging, copy and paste, phones, page sizes.
- [Publishing](./publishing): a static site from the designer or from a script.

The designer writes one file, `report.json`: [Report format](/reference/format/) describes it section by section, and
[Visual types](/reference/visuals/) lists every visual's fields and options. Every shortcut:
[Keyboard shortcuts](/reference/shortcuts).

# Image

An image from a URL.

In `report.json`: `"type": "image"`.

## Fields

None: it shows what its options say.

## Options

In the Format tab; `options` in `report.json`.

| Option | Label | Values | Default |
|---|---|---|---|
| `url` | Image URL | text |  |
| `alt` | Alt text | text |  |
| `fit` | Fit | `"contain"` (Contain), `"cover"` (Cover) | `"contain"` |

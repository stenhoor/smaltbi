# Parameter

A control for a what-if parameter: a slider or a dropdown that every measure using it follows.

In `report.json`: `"type": "parameter"`.

## Fields

None: it shows what its options say.

## Options

In the Format tab; `options` in `report.json`.

| Option | Label | Values | Default |
|---|---|---|---|
| `param` | Parameter name | text |  |

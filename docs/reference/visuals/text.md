# Text box

Formatted text (Markdown), with measures inside it.

In `report.json`: `"type": "text"`.

## Fields

Wells in the designer's Build tab; `fields` in `report.json`, by role.

| Role | Well | Takes | At most |
|---|---|---|---|
| `values` | Values for {0}, {1}, … | measures (a column is aggregated) | any |

## Options

In the Format tab; `options` in `report.json`.

| Option | Label | Values | Default |
|---|---|---|---|
| `text` | Text (markdown) | text (several lines) | (text) |
| `align` | Align | `"left"` (Left), `"center"` (Center), `"right"` (Right) | `"left"` |

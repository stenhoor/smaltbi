# Shortcuts

Keys and mouse in the designer, the model view and the viewer. Ctrl is ⌘ on a Mac. Keys don't act while you type in a
field, except Ctrl+S.

## Designer

| Keys | What they do |
|---|---|
| Ctrl+S | Download the report file (`<name>.smaltbi.json`) |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z, Ctrl+Y | Redo |
| Ctrl+A | Select every visual on the page |
| Ctrl+C, Ctrl+X, Ctrl+V | Copy, cut and paste the selected visuals (between pages and reports) |
| Ctrl+D | Duplicate the selected visuals |
| Delete, Backspace | Delete the selected visuals |
| ← → ↑ ↓ | Move the selected visuals a grid cell |
| Shift+← → ↑ ↓ | Resize the first selected visual a grid cell |
| Esc | Deselect |
| / | Search the fields |

## Fields pane

| Keys or mouse | What they do |
|---|---|
| Click | Add the field: to the selected visual's best well, or as a new visual |
| Ctrl+click | Select or unselect a field, to *Add* several or drag them together |
| Shift+click | Select the fields from the last one clicked to this one |
| ↓ in the search box | Go to the matches |
| ↓ ↑ | Move through the matches |
| Enter | Add the field |
| Space | Select the field |
| Esc | Clear the search |

## Wells

| Keys | What they do |
|---|---|
| Alt+↑, Alt+↓ | Move the focused field up or down its well |
| Delete, Backspace | Remove the focused field |

## Canvas

| Mouse | What it does |
|---|---|
| Shift+click, Ctrl+click | Add a visual to the selection |
| Drag the ⠿ grip | Move the visual (all selected ones, with several selected) |
| Drag the corner | Resize the visual |

## Model view

| Keys or mouse | What they do |
|---|---|
| Ctrl+wheel | Zoom |
| Delete, Backspace | Delete the selected relationship |
| Esc | Deselect |
| Drag a column onto another table's key | Relate the tables |

## Measure editor

| Keys | What they do |
|---|---|
| Ctrl+Enter | Test the expression |

## Viewer

The viewer, a published report, and the designer's Preview.

| Mouse | What it does |
|---|---|
| Click a mark (a bar, a slice, a row) | Filter the page to it; click it again, alone, to clear |
| Ctrl+click, Shift+click | Add a mark to the selection, or take it out |
| Double-click a mark | Drill down |
| Right-click a mark | Drill down, drill through, include or exclude it, copy its value |

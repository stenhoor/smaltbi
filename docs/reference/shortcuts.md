# Keyboard shortcuts

On a Mac, ⌘ works wherever this page says Ctrl. Shortcuts other than Ctrl+S don't apply while you type in a box.

## Anywhere in the designer

| Keys | What they do |
|---|---|
| Ctrl+S | Save the report file (downloads `report.json`) |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z, Ctrl+Y | Redo |

## The canvas (Report)

| Keys | What they do |
|---|---|
| `/` | Jump to the field search |
| Ctrl+A | Select every visual on the page |
| Ctrl-click, Shift-click | Add a visual to the selection |
| Arrows | Move the selected visuals a grid cell |
| Shift+arrows | Resize the first selected visual |
| Ctrl+C, Ctrl+X, Ctrl+V | Copy, cut and paste the selected visuals, also between reports |
| Ctrl+D | Duplicate the selected visuals |
| Delete, Backspace | Delete the selected visuals |
| Escape | Clear the selection |

## Fields

| Keys | What they do |
|---|---|
| Ctrl-click, Shift-click | Select several fields, then *Add* or drag them |
| ↓ | In the search box: go to the first match |
| Enter | In the search box: add the first match (or the selected fields) |
| Escape | In the search box: clear it |
| ↓, ↑ | On a field: move to the next or previous one (↑ from the first goes back to the search box) |
| Shift+↓, Shift+↑ | On a field: select it and the next or previous one |
| Space | On a field: select it, or clear it from the selection |
| Enter | On a field: add it (or the selected fields) |
| Escape | On a field: clear the selection, or go back to the search box |

## Wells

| Keys | What they do |
|---|---|
| Alt+↑, Alt+↓ | Move the focused field up or down the well |
| Delete, Backspace | Remove the focused field |

## Model view

| Keys | What they do |
|---|---|
| Delete, Backspace | Delete the selected relationship |
| Escape | Clear the selection |
| Ctrl+wheel | Zoom |

## Measure editor

| Keys | What they do |
|---|---|
| Ctrl+Space | Complete a table, a column or a `[` measure |
| Ctrl+Enter | Test the expression |
